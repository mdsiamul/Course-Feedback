# Course Feedback

A Chrome browser extension for providing course feedback.

## Work Process
- Just go to course feedback page and run the extension.

## Features

- Course feedback interface
- Simple and user-friendly popup
- Browser extension functionality
- Course-related feedback collection

## Project Structure

- `manifest.json` — Extension configuration
- `background.js` — Background service worker
- `content.js` — Content script
- `popup.html` — Extension popup interface
- `popup.js` — Popup functionality
- `icons/` — Extension icons
- `screenshots/` — Project screenshots

## Installation

1. Download or clone this repository.
2. Open Chrome and go to:
   `chrome://extensions/`
3. Enable **Developer mode**.
4. Select **Load unpacked**.
5. Choose the project folder.
